## Files
- `index.html` — Executive dual-profile portfolio with instant tab switching and print-to-PDF support for the active profile.
- `styles.css` — Responsive corporate editorial design system.
- `script.js` — Profile switcher, `?profile=sap` / `?profile=business` deep linking, clipboard share buttons, and navigation.
- `profile-public.json` — Machine-readable public data source (`profiles.sap` and `profiles.business`) for **JobApply AI**.
- `.gitignore` — Safeguards against committing private resumes, credentials, or private candidate records.

## Privacy Notice
This repository is **public**. Personal phone numbers, residential street addresses, compensation expectations, and work authorization documents are intentionally excluded and stored strictly offline in the private JobApply AI vault.

## Publishing on GitHub Pages
1. Push or upload all files in this directory to the root of `https://github.com/dsudheerk1-coder/dsudheerk1-coder.github.io` (`main` branch).
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** → **Branch: `main`** → **Folder: `/ (root)`**, and click **Save**.
4. Your site will publish at `https://dsudheerk1-coder.github.io/`.
